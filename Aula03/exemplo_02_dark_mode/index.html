Persistência com LocalStorage

Este exemplo demonstra como alternar o tema visual de toda a aplicação e salvar a preferência do usuário utilizando o localStorage do navegador. Ao recarregar a página, o tema escolhido é mantido automaticamente.

Experimente clicar no botão no canto superior direito para alternar entre os modos claro e escuro. Abra o console do navegador ou a aba Application (Local Storage) para inspecionar os dados salvos.
